# План релизов

## Релиз 1 — MVP

### Цель

Рабочий продукт для первых пользователей.

### Объём

- Регистрация и авторизация.
- Профиль пользователя.
- Главный экран.
- Библиотека упражнений.
- Создание программ.
- Запись тренировок.
- Подходы, повторения и веса.
- Таймер отдыха.
- История тренировок.
- Базовая аналитика.

### Критерий готовности

Пользователь может зарегистрироваться, заполнить профиль, найти упражнения, создать программу, провести тренировку с записью подходов/повторений/весов и отдыха, а затем просмотреть историю и базовые показатели прогресса.

### Текущий этап реализации

Первичная анкета, локальный профиль, стартовая/пользовательская программа, библиотека из 14 упражнений, локальная запись тренировок, восстановление незавершённой сессии, история и базовая аналитика уже реализованы. Начальная Supabase-схема с RLS подготовлена, но не применена. Для завершения MVP остаются аутентификация, синхронизация, наполнение каталога до 150–200 упражнений и медиа для упражнений.

## Следующие релизы

Сценарии восстановления и AI-тренера не входят в MVP. Их приоритет и объём будут определены после обратной связи первых пользователей.
