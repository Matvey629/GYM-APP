# План развития

Черновая последовательность реализации:

1. Уточнить пользовательские сценарии и визуальную систему.
2. Добавить аутентификацию и профиль.
3. Реализовать каталог упражнений и программы.
4. Реализовать журнал выполнения тренировок с локальным сохранением.
5. Добавить синхронизацию и миграции Supabase с политиками доступа.
6. Добавить аналитику прогресса и сценарии восстановления.
7. Оценить отдельный сценарий AI-тренера, его стоимость и ограничения.

Пункты — ориентир, а не обязательные сроки или обещание релиза.
