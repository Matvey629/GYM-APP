# Дизайн-система

## Принципы

- Сначала проектировать для мобильного экрана и управления большим пальцем.
- Использовать безопасные зоны, контрастные состояния и читаемые размеры текста.
- Показывать состояние загрузки, пустой список, ошибку и отсутствие сети на ключевых экранах.
- Сохранять общие токены оформления в `src/constants`; не копировать цвета и отступы между экранами.

## Текущая база

Тема Expo-шаблона находится в `src/constants/theme.ts`. Перед созданием новых визуальных компонентов нужно расширять эту базу и сохранять поддержку светлой/тёмной темы.

Конкретные цветовые токены, типографическая шкала и правила компонентов будут добавлены вместе с макетами продукта.
