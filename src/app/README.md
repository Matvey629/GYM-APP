# Маршруты

Expo Router превращает файлы экранов в маршруты. `_layout.tsx` содержит корневой Stack и поставщика данных; `(tabs)/_layout.tsx` защищает основные вкладки проверкой первичной настройки. `(tabs)/index.tsx` — Dashboard, остальные вкладки — каталог, программы, прогресс и профиль. `onboarding.tsx` — первоначальная анкета, `workout.tsx` — активная тренировка, `exercise/[id].tsx` — детали упражнения.

Группа `(tabs)` не добавляет сегмент URL. Маршруты и компоненты остаются внутри `src/`, как настроено в проекте.
