# Маршруты

Expo Router превращает файлы экранов в маршруты. ` (auth)/` группирует вход и регистрацию, `(tabs)/` — основные разделы, `exercise/[id].tsx` — динамическую карточку упражнения. Группы в скобках помогают организовать навигацию, не добавляя сегмент URL. `_layout.tsx` задаёт общий навигатор.

Маршруты остаются в `src/app`, потому что проект уже настроен на эту директорию.
