# Интеграции и общие функции

Здесь размещаются локальный адаптер сохранения (`app-storage.ts`), клиенты внешних сервисов (`supabase.ts`, `api.ts`, когда появится backend) и функции без привязки к конкретному экрану или предметной области (`utils.ts`). Секретные ключи в клиентский код не помещаются.
