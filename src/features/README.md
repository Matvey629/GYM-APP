# Функциональные области

Каждая подпапка содержит логику одного домена: `app-data` — локальное состояние и сохранение; `workouts` — журнал и выполнение занятий; `programs` — планы и генерация стартовой программы; `exercises` — локальный каталог. `auth`, `analytics`, `recovery` и `ai-coach` обозначают будущие области для следующих этапов. Экранная композиция остаётся в `src/app`, общая визуализация — в `src/components`.
