# Функциональные области

Каждая подпапка содержит логику одного домена: `auth` — аккаунт; `workouts` — журнал и выполнение занятий; `programs` — планы; `exercises` — каталог; `analytics` — расчёты прогресса; `recovery` — самочувствие и отдых; `ai-coach` — сценарии подсказок. Экранная композиция остаётся в `src/app`, общая визуализация — в `src/components`.
